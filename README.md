# chiefsmurph/homebrew-tap

```sh
brew install chiefsmurph/tap/git-drift
brew install chiefsmurph/tap/pingpigeon
```

| Formula | What |
|---|---|
| [git-drift](https://github.com/chiefsmurph/git-drift) | Find code that never made it to GitHub, on your laptop and your servers |
| [pingpigeon](https://github.com/chiefsmurph/pingpigeon-cli) | Email, push and text yourself from the terminal ([pingpigeon.app](https://pingpigeon.app)) |

Formulae are updated automatically by each project's release workflow.
